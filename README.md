# Supplier Performance & Risk Dashboard

Interactive Excel supply chain dashboard analyzing vendor performance, delivery reliability (OTD/Fill Rate), and inbound quality risks using relational data models and dynamic Pivot views.

## Key Highlights
- **Delivery Reliability:** Monitored On-Time Delivery (OTD), Order Fill Rates, and lead-time variance.
- **Quality Analytics:** Tracked defect rates (PPM), audit pass rates, and corrective action workflows across plants.
- **Data Architecture:** Built on relational star-schema modeling connecting transactional facts with master dimension tables.
